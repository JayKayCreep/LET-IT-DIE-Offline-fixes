# Changelog

## Full release — 5 October 2026

Both packages were downloaded, checked and approved for full release by the maintainer.

### Borderless + Texture Fix 0.2.0

- Borderless fullscreen and automatic removal of the supported engine's mip-fade transition.
- Several hours of in-game testing reported with the texture fix working and no crashes or other issues observed.
- Compatibility checks leave the texture setting untouched when the executable or engine state does not match.

### Borderless 0.1.1

- Borderless fullscreen only.
- Confirmed in-game with a desktop chat overlay.

### Package documentation

- Clear installation, removal and support instructions in both ZIPs.
- Correct repository links, standard MIT licence text and separate attribution notices.
- DLLs unchanged by the documentation refresh; ZIP checksums updated.

Other game builds, multi-monitor setups and other graphics wrappers remain unverified.
